# Flow source registry

この文書は flow catalog と generator の実装根拠を管理する。検索結果の snippet、出典を追えない code、名称が似ているだけの algorithm は実装根拠にしない。source record が `confirmed` になるまで、対応 descriptor は検索可能な `SourceBlocked` としてだけ production catalog に載せ、実行対象として選択させない。

## Record contract

各 record は次を固定する。

- stable source ID
- `project-specification`、`primary-paper`、`official-specification`、`official-implementation-doc`、`authoritative-secondary` の種別
- title、authors、year、DOIまたは恒久URL、参照version
- 対応する catalog ID
- 実装する定理、algorithm、pseudocode、variant
- 入力前提、出力、tie-breaking、利用する complexity/correctness claim
- codeを参照する場合のlicenseと、移植か独立実装か
- last reviewed date

`authoritative-secondary` は用語と既知のvariantの探索には使えるが、paper固有のcanonical descriptorを確定する一次根拠にはしない。
